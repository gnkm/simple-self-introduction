# Simple Self Introduction

## 概要

マークダウンファイル( `contents/self-introduction.md` )の情報をもとに
読みやすさを優先した洗練されたデザインの自己紹介ページを作る。

作者は派遣会社に所属し、他社の案件にアサインされている。想定読者は **同じ派遣会社の社員で、別の案件に入っている同僚**。採用担当や取引先向けの職務経歴ではない。

## 要件

- `pnpm dev` を実行するとサーバーが起動する
- サーバーが起動して、localhost:3210 にアクセスすると `contents/self-introduction.md` の内容のウェブページが表示される
- ウェブブラウザの機能でウェブページを PDF にしたとき、用紙は縦長 A4 とする。**2 枚以上になってよい**（1 枚に収める必要はない）。最終成果物は同僚へ渡す PDF で、1 ページ目で「今どの案件で何をしている人か」が分かること
- PDF ではクリック可能なリンクが失われる。frontmatter の github / blog / x は氏名の近くに出し、**ラベルと URL を併記**する（URL は省略しない）
- 見出し 2 ごとの区切りが一目で分かる。余白を削って詰め込むより、読みやすさを優先する
- 大セクションは見出し 2、その中の項目は見出し 3。項目の内側の分類は見出し 4 にしてよい（レベルは飛ばさない）
- 読み手が知りたい順に並べる（別案件の同僚が先に「今何をしている人か」を掴めるよう、業務・スキル・資格を趣味より前）

## 希望技術スタック

- TypeScript
- [unifiedjs](https://github.com/unifiedjs/unified)
- Vite
- pnpm
- Biome

## デザイン方針

詳細な再現仕様は [design-system.md](./design-system.md)。

- 洗練された印象
- 区切りは余白を主とする。線はヘッダ下・見出し 2 直下・表の行など、水平方向で役割が明確なものに限る。セクションを枠で囲まない
- マークダウンでの箇条書きは、ウェブページにした際、1 列に表示しなくてもよい。場合によっては表にしてもよい。
