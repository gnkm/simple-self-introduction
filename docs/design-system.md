# デザインシステム

Simple Self Introduction の見た目を再現するための契約。数値は現行 CSS（`src/styles/page.css` / `list-layout.css`）に合わせる。トークンや余白を変えたら **本文書と CSS を同時に直す**。コードだけで見た目を上書きしない。

## この文書の位置

| 文書 | 役割 |
| --- | --- |
| [01-seed.md](./01-seed.md) | 意図の起点。衝突したら最優先 |
| [srs.md](./srs.md) | 機能・印刷・検証の契約。6 章は本文書の要約 |
| **本文書** | 色・活字・余白・部品の再現仕様 |
| コード | 実装。見た目の正本ではない |

衝突時: **seed > SRS > 本文書 > コード**。

対象読者: 実装するエージェントと、PDF の見た目を直す人。

---

## 1. 目的と媒体

最終成果物は **同僚へ渡す PDF**（Chromium の印刷 → PDF に保存）。画面はプレビューであり、ランディングページではない。

作者は派遣会社に所属し、他社の案件に入っている。想定読者は **同じ派遣会社の社員で、別の案件にアサインされている同僚**。採用担当・取引先・不特定の初対面向けではない。

PDF はチャットやメールで回り、スクロールできず、1 ページ目で判断が終わり、単独ページが切り出され、白黒印刷されうる。テキストは選択・検索できること（画像化しない）。

| 項目 | 値 |
| --- | --- |
| 判型 | A4 縦 |
| ページ数 | 2 を標準。3 を超えないよう余白は削りすぎない。1 枚に収めるために 9pt 未満へ縮小しない |
| 1 ページ目 | 「今どの案件で何ができる人か」が完結していること（氏名・サマリ・業務・スキル・資格が先） |
| `@page` 余白 | **12mm**（10mm〜14mm の範囲。20mm にはしない。情報量が落ちる） |
| 印刷本文 | **11pt**（下限 9pt） |

技術上の見た目制約: プレーン CSS のみ。React / Tailwind / コンポーネントライブラリ / アイコンフォント / アニメーションライブラリは使わない。システムフォントのみ（ファイル同梱なし）。

## 2. 原則

優先順位（SRS と同じ）: **情報を欠落させない > 読みやすさ（区切り・余白） > 整列 > 装飾・動き**。

1. **編集的で静か。** 同じ会社の同僚へ渡す人物紹介。採用用の職務経歴書、スタートアップ LP、ダッシュボード、ガラスモーフィズム、大きなグラデーション、ヒーロー画像は禁止。
2. **区切りは余白が主。** セクションを枠で囲まない。左右の縦線・左アクセントバーは置かない。
3. **線は水平で、役割が一言で言えるものだけ。** 下表以外の罫線を足さない。
4. **斜め読みできる階層。** 大見出し・小見出し・本文のサイズ差を保つ。見出しは直後の本文の持ち物（上余白 > 下余白、およそ 3:1）。
5. **色に意味を持たせない。** スキルの分類はラベル。印刷時のタグ塗り分けに依存しない。アクセントはリンクと見出し 2 のごく一部。
6. **PDF でリンクが死んでも情報が残る。** ヘッダはラベルと URL を併記。本文の自動リンクはスキームを省いてよい（`href` は絶対 URL）。

### 線の言語（使うもの / 使わないもの）

| 使う | 役割 | 仕様 |
| --- | --- | --- |
| ヘッダ下の全幅 1px | 身元と本文を分ける。**ページ唯一の全幅ルール** | `border-bottom: 1px solid var(--color-rule)` |
| 見出し 2 の短い下線 | セクションラベル | 見出し幅（`width: fit-content`）。色は見出しと同じ `currentColor`（アクセント）。罫線色だと短い見出しが消える |
| 資格表の行の下線 | 行を追う | `--color-rule`、最終行は線なし。縦罫は置かない |
| 見出し 3 の行頭の右向き三角 | 大見出しの内訳である印 | 補助色。`clip-path` の三角形（高さ 0.58em、幅 0.5em）。文字の ▶ は使わない |
| タグの枠 | チップの形 | 画面は `--color-rule`＋塗り。印刷は本文色の枠＋白塗り |

使わない: セクション四辺の枠、左 4px アクセント、見出し 3 ブロック間の上罫線、カードの影、区切りのための `<hr>` 量産。

## 3. 情報設計

読み手が知りたい順。別案件の同僚は、先に **今の担当とできること** を掴む。趣味は後ろ（人となりはサマリ 1〜2 行で足りる）。採用用の経歴順ではない。

```text
1. 氏名 / 時点 / サマリ / リンク
2. 現在の業務内容
3. スキル
4. 資格
5. 今後挑戦したいこと
6. 趣味
```

重複する箇条書き（業務の担当リストと、直後の見出し 3 が同じ）は置かない。導入文＋見出し 3 で足りる。

見出しレベルは飛ばさない。大セクションは見出し 2、項目は見出し 3、項目の内側の分類だけ見出し 4（現行は趣味「生成 AI と戯れる」内の「課金中のサービス」）。見出し 4 は新しいセクションやグリッドの単位にしない。

## 6. 余白

画面のページパディング: `2rem 1.35rem 3rem`。カラム最大幅 `--page-max-width: 186mm`（A4 幅 210mm − 左右 12mm）。画面でもこの幅で中央寄せ。

| トークン / 関係 | 値 | 意味 |
| --- | --- | --- |
| `--section-gap` | **2.5rem** | `main` のセクション間。見出し 2 の「上余白」の本体 |
| `main` の上 | 2rem | ヘッダ罫線のあと |
| 見出し 2 下 | 0.65rem ＋ 下線用 padding 0.38rem | 下は狭く |
| 見出し 3 下 | 0.55em | 直後の本文へ |
| `.h3-grid` の gap | **1.85rem** | 見出し 3 ブロック同士。下 0.55em に対しおよそ 3:1 |
| `.h3-grid` の下 | 1.15rem | |
| 見出し 4 上 / 下 | 0.85em / 0.28em | 見出し 3 ブロック間より狭い。兄弟の h3 に見せない |
| 段落下 | **1.05em** | 行間より一段広く。塊が見えるように |
| タグ間 | 0.4rem × 0.55rem | |
| スキル行 | 行間 0.5rem、ラベルとタグ 1.25rem | |
| 縦箇条書き | 左 1.35em、項目下 0.2rem | |

見出しの上下比は「上が広く下が狭い」。見出し 2 の上はセクション間ギャップ、下は 0.65rem。見出し 3 の上はグリッドギャップ、下は 0.55em。

## 8. 部品

### 8.1 ヘッダ

`.header-top` は横並び、`justify-content: space-between`、ベースライン揃え。左が `h1`、右が `.as-of`（`updated` が無いときは出さない）。

`.lead` は `summary` があるときだけ。本文より大きく、行間 1.85。何ができる人かの輪郭。趣味の要約で代用しない。

`.profile-urls` は横並び折り返し。各 `li` の `::before` はアクセント色のダイヤ（`clip-path: polygon(50% 0, 100% 50%, 50% 100%, 0 50%)`、一辺 0.42em）。`align-items: center`（回転の菱形だと文字と縦がずれる）。

リンク内側: `.url-label`（GitHub / Blog / X）＋ `.url-plain`（href と同じ URL）。`a` 自体は下線なし、URL 側だけ下線。ホバーでリンク色が本文色へ。QR コードは置かない。

ヘッダ下パディング 1rem のあと、1px 全幅罫線。

時点の表記: frontmatter `updated` が `YYYY-MM` または `YYYY-MM-DD` なら「YYYY 年 M 月時点」。

### 8.2 セクションと見出し 2

見出し 2 ごと `<section>`。背景透明。枠なし。`break-inside: avoid` をセクション全体には掛けない（長い塊が次ページへ飛ぶ）。

見出し 2: アクセント、字間 0.12em、短い下線、`break-after: avoid`。

### 8.3 見出し 3 ブロック

連続する見出し 3 は `.h3-grid` > `.h3-block`。現行 CSS は **1 列**（`grid-template-columns: 1fr`）。画面幅が足りれば 2 列にしてよいが、モバイル専用レイアウトは作らない。ブロック間は余白のみ（上罫線なし）。

見出し 3 の行頭に `::before` で右向き三角（`clip-path: polygon(0 0, 100% 50%, 0 100%)`、高さ 0.58em、幅 0.5em、`--color-muted`）。大見出しの内訳であることを示す。`display: flex` と `align-items: center`。文字の `▶` は環境によって絵文字になるので使わない。横線（壊れた箇条書き）、ダイヤ（URL ビュレット）、セクション全高の縦線にもしない。クリック可能な開閉にはしない。

### 8.4 見出し 4

見出し 3 ブロックの内側だけ。サイズは本文相当、補助色、上 0.85em / 下 0.28em。グリッド列にしない。

### 8.5 タグ（チップ）

`.tags` は flex 折り返し。各 `li` は `border-radius: 999px`、パディング `0.1rem 0.5rem`、画面は `--color-tag-bg` ＋ 1px `--color-rule`。影なし。印刷は 4 章のとおり枠線＋白。

適用: 見出し 4「課金中のサービス」直下のフラットリスト。スキルの子。入れ子リストの子側。

### 8.6 スキル行

Markdown は親＝カテゴリ、子＝項目。DOM は `.skill-groups`（2 列グリッド: `max-content 1fr`）> `.skill-group`（`display: contents`）> `.skill-label` ＋ `ul.tags`。

```text
言語        [Python] [TypeScript] [PHP] …
フロント    [React] [Astro] …
```

ラベル列の幅は最長ラベルに揃う。親をチップにしない。色の塗り分けで階層を示さない。「業務で常用 / 趣味」の枠線差は採用しない。

### 8.7 資格表

`.certs`。列は「名称」「取得」。ソースの末尾括弧を取得列にしてよい。新しい順。ヘッドはゴシック・補助色。取得列は `nowrap`、幅 9em、補助色。行の下線のみ、最終行は線なし。縦線なし。

### 8.8 縦箇条書き

その他のフラットリストは `.list-stack`（通常の黒丸、1 列）。遊びリストなど。密に並べる例外は 3.1.3（資格・スキル・課金）だけ。

入れ子のその他は `.list-groups` / `.list-parent` ＋子タグ。見える階層は 2 段まで。

### 8.9 リンク

`http(s)` は `target="_blank"` と `rel="noopener noreferrer"`。空の `href` は残さない。ホバーは色が本文へ変わる程度。スクロールアニメ・フェードインは禁止。

本文の自動リンク表示は `github.com/…` のようにスキームなし。

## 9. 印刷と改ページ

```css
@page { size: A4 portrait; margin: 12mm; }
```

印刷時 `body` は 11pt、`max-width` 解除、画面用パディングなし。背景 `#fff`。

改ページ:

- `h2, h3, h4 { break-after: avoid; }`（見出しだけページ末に残さない）
- `.h3-block` / `.skill-group` / `.tags` / `tr` に `break-inside: avoid`
- `p { orphans: 2; widows: 2; }`
- 長い `section` 全体は閉じ込めない

`.print-id` は画面 `display: none`。印刷だけ `position: fixed; bottom: 0; right: 0;` で氏名と時点。Chrome の `@page` カウンタや Vivliostyle は使わない。ブラウザのヘッダー/フッターはダイアログでオフ（README）。

配布 PDF はテキスト選択できること。ファイル名の例: `gnkm-profile-202608.pdf`。`<title>` は氏名。

## 11. 禁止する見た目

- 絵文字、大きな丸アイコン、スキルのプログレスバー
- ドロップシャドウの多用、ぼかし、ホバーで大きく動く演出
- 原色のボタン、カードの立体感
- セクションごとの背景塗り分け（タグ以外）
- セクションを四辺の枠や左アクセントの縦線で囲むこと
- QR コード、組版ツール前提のページ番号
